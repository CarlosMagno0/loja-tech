# 🛒 Loja Tech

🔗 Deploy do projeto: https://lojatech.netlify.app/

---

## 📌 Objetivo do Projeto

A **Loja Tech** é um site fictício de e-commerce desenvolvido como atividade acadêmica, com o objetivo de praticar habilidades de desenvolvimento web utilizando HTML, CSS e React.

O sistema simula uma loja online de produtos tecnológicos, permitindo navegação entre páginas, visualização de produtos e gerenciamento de produtos através de um CRUD completo.

---

## 🌐 Acesso ao Projeto

O projeto está hospedado e pode ser acessado pelo link abaixo:

👉 https://lojatech.netlify.app/

---

## 📄 Estrutura do Site

O site é composto pelas seguintes páginas:

* 🏠 Página inicial (Home) com produtos em destaque e notícias
* 🖱️ Página de produtos com CRUD em React
* 🛒 Página de carrinho (simulação de compra)
* 📞 Página de contato com formulário

---

## ⚙️ Tecnologias Utilizadas

* HTML5
* CSS3
* ReactJS
* JavaScript
* LocalStorage

---

## 🚀 Funcionalidades

* Cadastro de produtos
* Listagem de produtos
* Edição de produtos
* Exclusão de produtos
* Persistência de dados com LocalStorage
* Layout responsivo
* Navegação entre páginas
